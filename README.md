# CppForDevelopers
Kodexempel, kodbaser, lösningsförslag, och lösningar för kursen C++ for developers.

## Extensions i VS Code

Detta är de extensions jag använder mig av:

* C/C++ Extension Pack (identifier: ms-vscode.cpptools-extension-pack)
* Makefile Tools (identifier: ms-vscode.makefile-tools)
* Markdown PDF (identifier: yzane.markdown-pdf) - för att skapa PDF:er av Markdown-filer (högerklicka i filen och välj ```Markdown PDF: Export (pdf)```)
* vscode-pdf (identifier: x) - för att öppna PDF:er i VS Code
